# 无 API Key 的日报生成流程

DailyReport 可以只负责采集和整理工作轨迹，不必在程序内调用付费 API。

## 使用方式

1. 让 DailyReport 在工作期间保持运行，并在设置中启用需要的监控项。
2. 下班前进入“报告中心”。
3. 点击“复制 AI 提示词”，然后粘贴到任意支持长文本的 AI 对话网站；或者点击“导出 AI 总结包”，上传生成的 `.md` 文件。
4. AI 返回结果后，可把 Markdown 保存到自己的日报系统、笔记或团队协作工具。

导出的文件已经包含完整指令，要求 AI：

- 使用所选的中文或英文；
- 按项目或功能归纳开发内容；
- 汇总 Git、构建、测试、技术查阅和文档学习；
- 区分事实与推断，不虚构成果；
- 输出结构清晰的 Markdown 日报。

## 导出内容

默认可能包含：

- 编辑器名称、当前文件名和工作区名称；
- 监控目录中的文件创建、修改、删除记录；
- Git 提交信息及涉及的文件名；
- 构建和测试活动；
- 浏览器页面标题、域名及清洗后的 URL；
- 打开的 PDF、Word、PPT、Excel 等资料名称；
- 各类活动的时间和数量汇总。

默认不会包含：

- 源代码正文或代码片段；
- PDF、Word 等文档正文；
- 浏览器密码、Cookie、用户信息和 URL 片段；
- URL 查询参数，除非用户在设置中主动开启；
- 浏览器无痕模式的完整历史。

上传前仍建议快速检查文件，删除不希望交给第三方 AI 的项目名、文件名、网页或资料名称。若工作内容受保密协议约束，优先使用本地 Ollama，或只在获准的企业 AI 服务中处理。
